# kaoyan-math2

考研**数学二**错题分析 —— Claude Code skill。

按 S1-S6 闭环分析错题：

- 拆最小知识点（叶子级粒度）
- 查错题账本（命中报次数 + 历史）
- 归因 + 思路来源（题眼 / 选路 / 岔路 / 信号 / 退路）
- 难度对标往年数二真题（送分 / 基础 / 中档 / 拔高 / 压轴）
- 数二考纲相符性判定（完全 / 部分 / 不相符）
- 文件库类似考法题（≥3 道三阶梯，按相关性 + 难度分布）
- 按反馈更新掌握度（L0-L4 + 思路通/未通）
- 归档、更新账本

## 安装

```bash
git clone https://github.com/jinglinghong713-rgb/kaoyan-math2.git ~/.claude/skills/kaoyan-math2
```

## 触发词

「分析错题」「数学二错题」「错题分析」「我哪块弱」，或直接贴出错题（题干 + 作答 + 参考答案）。

## 说明

- 题目、讲解、知识点均取自文件库，零幻觉、禁造题。
- 明确不收录数二不考内容（概率论、级数、三重积分、曲线曲面积分等）。
- 使用前请按 skill 内要求提供文件库路径。
